# Research library manifest

This directory contains only papers obtained from author preprints, arXiv, or institutional repositories that explicitly expose a public download. No access controls were bypassed. A local PDF is not included when only a paywalled publisher page, abstract, or bibliographic record was available.

The review in [`../docs/literature-review.md`](../docs/literature-review.md) distinguishes what each source actually demonstrates from what is proposed for this project. `references.bib` is the machine-readable bibliography.

## Integrity and maintenance

- Re-download only from the source URLs above, then validate that the first bytes are `%PDF` and that a PDF parser can enumerate all pages.
- Do not add publisher PDFs obtained through personal subscriptions unless redistribution is explicitly permitted.
- Avoid duplicate preprint/publisher copies. The local filename identifies the analyzed version.
- The unusually large `li-zhang-2014-hodge-tdgl.pdf` is the arXiv source itself, not a duplicate; its figures/fonts make text extraction slow.
